      About Our Project

      Drug Interaction Checker is an educational student project designed to demonstrate how medicine reference information can be searched and displayed through a web application.

      Easy Medicine Search

      Type into either search field to filter sample medicines in real time and pick items from a clean suggestion list.

      Simple Interaction Lookup

      Select two different sample medicines and review structured demonstration records or clear missing-record notices.

      User-Friendly Interface

      Built with clear healthcare styling, accessible controls, and a responsive layout for desktop, tablet, and mobile screens.

      Safety Information

      This application is an educational software demonstration only. It does not provide medical advice, diagnosis, or treatment recommendations. Sample data is fictional. Always consult a qualified doctor or pharmacist about medicine-related questions. A missing record does not establish that a medicine combination is safe.
